# O design aprovado — o PRIMEIRO

`OrthoDontic Intelligence.dc.html` é **o design aprovado**. Foi sobre ele
que o cliente disse "tô gostando do design". Ele saiu do **Claude Design**
(projeto `orthodontic-design-system-7aecc444…`) e foi entregue no zip
`Orthodontic_Intelligence_portal.zip` de 8/ago 15:59 — o primeiro zip de
portal que existiu.

`OrthoDontic Intelligence v2.dc.html` está aqui **só para comparação**.
É a versão seguinte, e **não** é a aprovada.

`PRIMEIRO-DESIGN.png` e `PRIMEIRO-DESIGN-inteiro.png` são capturas do
arquivo aprovado renderizado, para quem não quiser abrir o HTML.

## Como abrir

Os `.dc.html` são arquivos de canvas do Claude Design: o runtime é o
`support.js` ao lado, e ele injeta React/d3 de CDN. Num ambiente sem
saída para `unpkg.com`, baixe as libs e desvie os `src` para o disco —
sem isso a tela fica só o fundo navy e parece quebrada.

## Regra

**Design se faz no Claude Design.** Este repositório guarda a referência,
os dados (`dados/portal/*.json`) e o prompt (`PROMPT-CASCO-V6.md`).
Nenhum casco/HTML de portal é escrito aqui.
